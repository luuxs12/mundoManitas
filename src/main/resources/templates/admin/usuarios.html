La contraseña debe tener al menos 8 caracteres, con mayúscula, minúscula, número y carácter especial. El usuario podrá cambiarla desde su perfil.

Antes de guardar

Revisa que el correo no esté duplicado y que el rol coincida con las funciones que tendrá el usuario.

  • El correo se usará como nombre de usuario para iniciar sesión.
  • El rol define las pantallas y permisos disponibles.
  • Puedes cambiar el estado o editar los datos después de crear la cuenta.
Si el usuario es docente, considera asignarle un módulo desde la sección de contenido.
